## SistemasFuncionarios

Este projeto é uma aplicação em Java desenvolvida para praticar a manipulação de arrays e Programação Orientada a Objetos (POO).

Tecnologia utilizada (JAVA 21, IDE Eclipse)

# Como executar no Eclipse
1. Clique em File e depois em Import.
2. Escolha Existing Projects into Workspace e selecione a pasta do projeto.
3. Com o projeto aberto, procure pelo arquivo TesteSistema.java no Package Explorer.
4. Clique com o botao direito nele e escolha Run As e depois Java Application.
5. O resultado vai aparecer na aba Console na parte de baixo do Eclipse.

# Descricao das classes

1. Classe Funcionario
Guarda os dados do colaborador como nome, cpf, cargo e salario. Ela aplica reajustes, 
demite o funcionario e mostra as informações na tela.

2. Classe Departamento
Gerencia um grupo de ate 5 pessoas. Ela controla quem entra no time, lista todo mundo que ja foi cadastrado e soma o salario de quem ainda esta trabalhando/ativo.

3. Classe TesteSistema
Serve para rodar o programa, criar o departamento e testar se os metodos estão funcionando.
